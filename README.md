<h2>🛠️ Troubleshooting & Common Questions</h2>

<h3>❔ The app won't start after installation</h3>
<p>Right-click the desktop icon and choose "Run as administrator." If that doesn't work, go to Windows Settings → Apps → Installed Apps, find RVC Desktop, and click "Modify" to repair the installation.</p>

<h3>❔ My voice sounds robotic or glitchy</h3>
<p>Try using a different voice model. Also, make sure your microphone is close to your mouth and background noise is minimized. In the Real-Time tab, lower the "Pitch Shift" setting to zero if you notice artifacts.</p>

<h3>❔ The model download is slow</h3>
<p>Models are hosted on cloud servers. Large models can take time. Try pausing antivirus software temporarily (some antivirus tools slow down downloads).</p>

<h3>❔ Where do I find more voices?</h3>
